# Ahmad Naqiuddin Haikal — Personal website

A responsive personal portfolio with parallax scrolling and reduced-motion support.

## Publish with GitHub Pages

1. Upload `index.html`, `styles.css`, `script.js`, and `.nojekyll` to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the branch containing these files, and select **/ (root)**.
4. Save and wait for GitHub to display the published website address.

GitHub Pages publishes the website publicly. Free accounts can use a public repository. Review existing repository contents before uploading to avoid replacing unrelated files.

## Edit

- `index.html`: content and links
- `styles.css`: typography, colors, responsive layouts
- `script.js`: scroll effects and motion preferences

The site uses Google Fonts with local fallback fonts. LinkedIn content is a static snapshot and is not synchronized automatically.
